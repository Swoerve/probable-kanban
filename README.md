## CDN - Content Delivery Network/s

A cdn is a network of servers placed strategically around the world that caches static content geographically closer to end users. It let's users have closer and faster acces to internet content like HTML pages, javascript files, stylesheets, images and videos.

## Monitoring

Monitoring is a system like the name/word says that monitors your programs/services and can even notify you when they stop working or work slower.

Monitoring services/programs simply monitor (bevakar) our things to see if they recognize bad things like it stops answering or works slow.
